# AI Scriptless interface

Source: [AI Scriptless interface](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-interface.htm)

Use AI Scriptless to build, run, and manage tests. Control execution, select commands and checkpoints, and interact with connected devices from the main workspace.

## Workspace areas

| Area | Role |
| --- | --- |
| **Top toolbar** | Control the test and its commands |
| **Left sidebar** | Commands, checkpoints, and embeddable tests |
| **Test editor** | Where the test steps are listed and edited |
| **Devices pane** | Interactive open device (similar to Manual Testing) |
| **Widgets pane (right)** | Interact with the open device; add actions to the test and/or device |
| **Action panel** | Basic open-device actions (home, screenshot, rotate, secure text, …) |

## Top toolbar

| Control | Description |
| --- | --- |
| **Tests** | New, open, save tests |
| **Variables / DataTables / Scheduler** | Test variables, DataTables, scheduled jobs |
| **Editor Actions** | Cut, Copy, Paste, Delete, Edit, Exclude |
| **Control elements** | Loop, Logical step, Condition |
| **Execute test** | Run the test |
| **Open Device** | Open the selected device in the devices pane |

Related: [Handle tests](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-handle-tests.htm), [Configure test variables](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-configure-test-variables.htm), [Edit tests](https://help.perfecto.io/perfecto-help/content/perfecto/ide/sm-edit-tests.htm), [Control constructs](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-execution-control-constructs.htm), [Execute tests](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-execute-tests.htm)

## Left sidebar

Collapsible. Tabs:

| Tab | Description |
| --- | --- |
| **Commands** | Common commands (Home, Select text, …), **Other Commands**, and **Embeddable Tests** (repository tests). Classic commands are available when creating a test for a real mobile device. |
| **AI** | AI Scriptless AI commands for natural-language steps independent of locators, UI language, or dynamic content. |

Related: [Add commands or checkpoints](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-add-commands-or-checkpoints.htm), [AI commands](https://help.perfecto.io/perfecto-help/content/perfecto/sm-commands-and-checkpoints/ai-commands.htm)

## Test editor

Lists test steps (commands). Create a new test by adding commands/checkpoints, or open an existing test.

## Devices pane

Select a lab device and work with it like Manual Testing. Add actions to apps and/or to the test.

## Action panel (open device)

| Action | Notes |
| --- | --- |
| Close device | Release the device |
| Home | Device home screen |
| Lock / unlock screen | Prevent or allow interaction |
| Take screenshot | Capture device screen |
| Rotate | Rotate device |
| Secure text | Enter secure text in the selected field |
| Mute / unmute | Audio |
| Reset device size | Reset display scale to 1:1 |

Related: [Supported actions on open devices](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-supported-actions.htm), [Keyboard shortcuts](https://help.perfecto.io/perfecto-help/content/perfecto/ide/scriptless-mobile-keyboard-shortcuts.htm)
